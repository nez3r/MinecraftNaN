# Minecraft NaN

Minecraft NaN - хоррор-проект на основе оригинального исходного кода Minecraft Beta 1.7.3 от Mojang. В проект добавлены синхронизированные события клиента и
сервера, визуальные глитчи, эффекты чата, порча инвентаря и другие элементы.

## Требования

- Java 8 (для компиляции рекомендуется JDK 8)
- Git
- Для Android можно использовать Zalith Launcher с совместимой Java 8

Проект сохраняет стиль старого кода Beta 1.7.3 и по возможности поддерживает
старые окружения запуска на Java и LWJGL.

## Структура репозитория

- `minecraft/src` - исходный код клиента
- `minecraft/game` - папка игры клиента, ресурсы и сохранения
- `minecraft_server/src` - исходный код выделенного сервера
- `minecraft_server/game` - конфигурация сервера и данные мира
- `minecraft/game/resources` - звуки и другие ресурсы
- `build` - собранные артефакты клиента и сервера
- `.vscode/launch.json` - конфигурации запуска VS Code

`NaNManager` содержит планировщик событий и клиентские эффекты. Серверный
менеджер выбирает события и отправляет их подключённым игрокам через
пользовательский пакет `Packet201HorrorEvent`.

## Сборка

Используйте JDK 8 и существующие инструменты проекта для подготовки клиента и
сервера. Исходные директории:

```text
minecraft/src
minecraft_server/src
```

Добавьте библиотеки из `libraries/` в classpath, включая LWJGL, LaunchWrapper и
звуковые библиотеки. Собранные JAR-файлы помещаются в `build/`.
Не используйте более новую JDK, если старый toolchain не был специально
настроен для неё: поддерживаемое окружение компиляции - Java 8.

## Запуск

Откройте репозиторий в VS Code и выберите одну из конфигураций:

- `NaN Client`
- `NaN Server`

Конфигурация запуска использует `minecraft/game` и `minecraft_server/game` как
рабочие директории. Для проверки сетевых событий сначала запустите сервер,
затем подключите клиент.

Для Android скопируйте собранные файлы игры и необходимые библиотеки в профиль
Zalith Launcher. Выберите Java 8 и укажите поддерживаемые устройством natives
LWJGL.
