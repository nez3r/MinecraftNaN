# Ивенты NaN

Используйте следующие команды в чате или консоли сервера:

```text
/event <string>
/next
/mst
```

`/mst` показывает следующее запланированное событие. `/next` запускает
следующее событие в общем порядке. На сервере отладочные команды обрабатываются
сервером, а выбранное событие отправляется подключённым игрокам.

## Список ивентов

| String | Ивент | Описание |
| --- | --- | --- |
| `voxel` | Крах вокселей | Фиолетово-красное искажение изображения. |
| `bleed` | Кровотечение кадра | Кратковременный визуальный глитч. |
| `redtext` | Красный текст | Заполняет экран быстро меняющимися красными символами. |
| `inventory` | Порча инвентаря | Навсегда заменяет отображаемые названия предметов. |
| `loot` | Случайная добыча | Выдаёт случайный предмет; стакаемые предметы - от 1 до 32 штук. |
| `redbars` | Красные полосы | Тонкие дёргающиеся полосы, после события наступает ночь. |
| `block` | Блоки в небе | Создаёт 20-50 блоков земли, булыжника или досок на Y=80-100. |
| `cobweb` | Паутина рядом | Создаёт паутину рядом с игроком. |
| `insults` | Оскорбления | Пишет красные сообщения от имени игрока в течение 4 секунд. |
| `shuffle` | Перемешивание инвентаря | Случайно перемещает предметы основных и броневых слотов. |
| `minimal` | Минимальная прорисовка | Уменьшает дальность прорисовки на 20 секунд. |
| `sign` | Табличка no way | Создаёт рядом с игроком табличку с текстом `no way`. |
| `invert` | Инверсия экрана | Инвертирует изображение игры на 8 секунд. |
| `drop` | Выброс активного предмета | Выбрасывает весь стак из выбранного слота. |
| `shake` | Тряска окна | Трясёт окно игры в оконном режиме. |
| `error` | Фейковая ошибка fullscreen | Показывает ошибку fullscreen-enabler и запускает отложенную последовательность красного текста. |
| `chatspam` | Спам символами | Отправляет случайные символы в чат 10 секунд. |
| `jitter` | Дёрганье интерфейса | Постоянно трясёт кнопки и текст меню. |
| `redbuttons` | Красные кнопки | Постепенно и навсегда окрашивает кнопки интерфейса в красный. |
| `title` | Испорченное название окна | Каждый тик меняет заголовок окна; длина растёт от 1 до 15 символов. |
| `debug` | Порча F3 | Постепенно скрывает строки отладочной информации и координаты. |
| `menushake` | Тряска меню | Сильно трясёт окно 5 секунд после выхода из мира. |
| `camerashake` | Тряска камеры | Сильно трясёт камеру во всех направлениях 10 секунд. |
| `text` | Порча текста | Заменяет текстовые поверхности случайными символами на 30 секунд. |
| `stack` | Порча стаков | Меняет отображаемый предел стака на 32-78 на 5 минут, затем возвращает 64. |
| `log` | Порча лога | Печатает случайные символы в лог каждый тик 15 секунд. |
| `terrain` | Порча terrain.png | Искажает координаты текстуры и рисует 50 аддитивных копий HUD с белыми следами 15 секунд. |

Планировщик не допускает последовательного повторения событий `block`,
`cobweb` и `insults`. Сервер также пропускает событие, если нет подключённых
игроков.
